# Dawg Viewer 0.3.0

Dawg Viewer 0.3.0 expands the application from a telemetry viewer into a more complete analysis, live-monitoring, and vehicle-configuration workspace.

## Highlights

### Analysis workspace

- Added configurable worksheets for organizing analysis views.
- Added time plots, XY and G-G plots, histograms, statistics, and value displays.
- Added GPS track maps, lap overlays, time-slip comparisons, and reference runs.
- Added math channels for deriving reusable signals from recorded data.
- Added spectrum analysis and signal filtering tools.
- Added launch, wheel-slip, aerodynamic, and GPS gap-filling analysis tools.

### Live telemetry

- Added live track mapping and lap timing.
- Added support for opening live telemetry in the Viewer workspace.
- Added a test mode that supplies simulated vehicle data without requiring a connected car.
- Added configurable Default and Bento live layouts.
- Added channel metadata and calibration editing.
- Improved live timing by using device timestamps and handling reordered or late telemetry rows.

### Vehicle configuration

- Added vehicle specifications and configuration management.
- Added sensor-position editing with a vehicle diagram.
- Added saved setups, presets, import and export, and startup restoration.
- Added polynomial, lookup-table, and gear-based channel calibrations.

### Reliability and performance

- Improved telemetry discovery on systems with multiple network interfaces.
- Prevented conflicting attempts to open the same log concurrently.
- Improved log serving and transfer behavior.
- Reduced avoidable allocations during telemetry streaming.
- Improved cleanup, cancellation, and repeated-action handling across asynchronous workflows.

### Documentation and development

- Reorganized the documentation for users, contributors, and maintainers.
- Added technical architecture and development documentation.
- Added AI contribution guidance and repository-level agent instructions.
- Expanded build and packaging support, including Windows ARM64.

Existing configuration and recorded telemetry should remain compatible. Users should review saved layouts, channel calibrations, and vehicle profiles after upgrading because the available configuration surface has expanded substantially.
